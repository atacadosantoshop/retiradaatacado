# Atacado Santo Shop

Controle de estoque de iPhones, fornecedores que retiram aparelhos e cobrança pelo WhatsApp.

## Funções
- Cadastro de aparelhos (modelo, armazenamento, cor, IMEI, condição, bateria, custo e repasse)
- Lançamento de retirada com valor, fornecedor e pessoa autorizada
- Cadastro de fornecedores e das pessoas autorizadas a retirar
- Cobranças agrupadas por fornecedor, com link pronto para o WhatsApp

## Como usar
Abra o `index.html` no navegador ou ative o GitHub Pages em **Settings → Pages → Deploy from a branch → main / (root)**.

Fora do Claude, os dados ficam salvos no navegador de quem está usando (localStorage).
